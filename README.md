# Neck Map

A guitar practice companion in a single page: scale positions, chord tones, soloing scales for any chord progression, the seven modes and play-along backing tracks.

## Tabs

- **Neck** – the five CAGED positions (or the whole neck) for any key and mode, with pentatonic, chord-tone rings and characteristic notes.
- **Chords** – any chord type on any root, colour-coded by role (root, 3rd, 5th, 7th), with the diatonic chords of the current key one tap away.
- **Songs** – type a progression; get the key, the home mode, a scale for the whole song and a scale for every chord. Play it as a backing track.
- **Theory** – the seven modes, a mode comparer, the CAGED table and a legend.
- **Play** – drone, mode vamp, 12-bar blues or your own song, with tempo, click and "neck follows the chord".

## Publish on GitHub Pages

1. Create a repository and upload `index.html` and `teacher.jpg` to its root.
2. In the repository go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
3. After a minute the site is live at `https://<your-username>.github.io/<repository>/`.

Direct links to a tab work with a hash, for example `…/#songs` or `…/#chords`.
Settings are remembered per browser. Replace the placeholder introduction in the About box (search for "Add a short introduction") with your own text.
